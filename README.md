# Enterprise Multi-Site Network Infrastructure Design and Implementation

## Project Overview

This project demonstrates the design, implementation, configuration, and troubleshooting of a simulated enterprise network connecting two continents distributed offices.

The network architecture incorporates Cisco routing and switching technologies, network segmentation, redundancy and security controls

## Network Locations

Africa
Asia

## Technologies Implemented

- Cisco IOS Routing and Switching
- VLANs and 802.1Q Trunking
- Inter-VLAN Routing
- OSPF Dynamic Routing
- HSRP Gateway Redundancy
- EtherChannel
- Spanning Tree Protocol
- DHCP
- Access Control Lists
- NAT/PAT
- Site-to-Site IPsec VPN
- SSH
- SNMP and Syslog
- Port Security

## Project Objectives

1. Design a scalable enterprise network architecture.
2. Implement departmental network segmentation.
3. Establish secure connectivity between multiple locations.
4. Implement routing and gateway redundancy.
5. Apply network security controls.
6. Test connectivity, availability, and failover.
7. Document network configurations and troubleshooting procedures.

## Network Documentation

Network topology diagrams, device configurations, IP addressing plans, and testing results are provided in their respective folders.

## Testing and Validation

Testing includes inter-VLAN connectivity, inter-site routing, ACL enforcement, VPN connectivity, and redundancy failover.

*Note: All technologies and test results will be documented as they are implemented and verified.*
